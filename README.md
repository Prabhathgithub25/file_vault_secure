File Vault Secure

A Flask-based security application that protects files using password protection, One-Time Password (OTP) authentication, location-based verification, and a secret-code-based website locking mechanism.

Project Overview

File Vault Secure is designed to strengthen file access security by combining multiple verification methods. The project demonstrates the application of Python web development and security concepts. It also includes an AI chatbot that guides users through the website and helps them understand its features and functionality.

Key Features

Password Protection: Restricts access using password-based authentication.

OTP Authentication: Adds an additional verification step using a one-time password.

Location-Based Verification: Uses location-based checks as part of the access verification process.

Website Locking Mechanism: Automatically locks the website when a user attempts to unlock it using an incorrect password. Access is restored only after the correct secret code is entered.

AI Chatbot Assistance: Guides users through the website, explains its features, and helps them understand how to use the application.

File Protection: Supports secure file access through the application's verification workflow.

Technologies Used

Programming Language: Python

Web Framework: Flask

Security: Password authentication, OTP verification, location-based checks, and secret-code-based locking

AI Integration: AI chatbot for website guidance

Supporting Technologies: HTML, CSS, JavaScript

Project Objective

To explore how multiple authentication methods, website locking mechanisms, and AI-powered assistance can be combined in a web application to improve access control, file security, and user experience.
